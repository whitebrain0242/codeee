================================================================================
                    客户端命令参考手册
================================================================================

【重要说明】
- 参数严格区分大小写。
- 密码：4~64 位非空格字符；用户名：3~20 位字母/数字/下划线；群组名：2~32 位字母/数字/下划线/短横线。
- 所有服务器命令需先 LOGIN 登录后才能使用（REGISTER 除外）。

================================================================================
一、账号管理
================================================================================
REGISTER <用户名> <密码>
        注册新账号。
        示例：REGISTER Alice MyP@ssw0rd

LOGIN <用户名> <密码>
        登录已注册账号。
        示例：LOGIN Alice MyP@ssw0rd

LOGOUT
        注销当前登录，清除在线状态。

DELETE_ACCOUNT <当前密码> CONFIRM 注销
        示例：DELETE_ACCOUNT MyP@ssw0rd CONFIRM

QUIT
        断开与服务器的连接（客户端退出）。

================================================================================
二、聊天消息
================================================================================

MSG <用户名> <消息内容>
        发送私聊消息（仅好友，且对方未屏蔽你）。
        示例：MSG Bob How are you?

GROUP_MSG <群组名> <消息内容>
        发送群聊消息（仅群成员）。
        示例：GROUP_MSG DevTeam Meeting at 3pm

================================================================================
三、好友管理
================================================================================
ADD_FRIEND <用户名>
        发送好友申请。
        示例：ADD_FRIEND Bob

ACCEPT_FRIEND <用户名>
        接受对方的好友申请。
        示例：ACCEPT_FRIEND Alice

REJECT_FRIEND <用户名>
        拒绝对方的好友申请。
        示例：REJECT_FRIEND Alice

REMOVE_FRIEND <用户名>
        删除好友关系，同时清除双向屏蔽。
        示例：REMOVE_FRIEND Bob

BLOCK_FRIEND <用户名>
        屏蔽好友（仅好友可屏蔽），对方无法给你发私聊或私密文件。
        示例：BLOCK_FRIEND Bob

UNBLOCK_FRIEND <用户名>
        解除屏蔽。
        示例：UNBLOCK_FRIEND Bob

FRIENDS
        列出所有好友及其在线状态。

FRIEND_REQUESTS
        列出收到的和发出的好友申请。

BLOCKED_FRIENDS
        列出已屏蔽的好友列表。

================================================================================
四、群组管理
================================================================================
CREATE_GROUP <群组名>
        创建新群组（你成为群主）。
        示例：CREATE_GROUP DevTeam

DISSOLVE_GROUP <群组名>
        仅群主可用，解散群组，所有成员被移除。
        示例：DISSOLVE_GROUP DevTeam

APPLY_GROUP <群组名>
        申请加入群组（需群主/管理员审批）。
        示例：APPLY_GROUP DevTeam

LEAVE_GROUP <群组名>
        主动退出群组（群主不可离开，只能解散）。
        示例：LEAVE_GROUP DevTeam

MY_GROUPS
        列出已加入的所有群组及角色。

GROUP_MEMBERS <群组名>
        查看群组成员列表（仅成员可查看）。
        示例：GROUP_MEMBERS DevTeam

ADD_GROUP_ADMIN <群组名> <用户名>
        仅群主可用，将成员提升为管理员。
        示例：ADD_GROUP_ADMIN DevTeam Bob

REMOVE_GROUP_ADMIN <群组名> <用户名>
        仅群主可用，将管理员降为普通成员。

GROUP_REQUESTS <群组名>
        仅群主/管理员可用，查看待审批的入群申请。
        示例：GROUP_REQUESTS DevTeam

APPROVE_GROUP <群组名> <用户名>
        仅群主/管理员可用，批准用户入群。
        示例：APPROVE_GROUP DevTeam Alice

REJECT_GROUP <群组名> <用户名>
        仅群主/管理员可用，拒绝用户入群申请。
        示例：REJECT_GROUP DevTeam Alice

REMOVE_GROUP_MEMBER <群组名> <用户名>
        仅群主/管理员可用，将成员移出群组。
        示例：REMOVE_GROUP_MEMBER DevTeam Charlie

================================================================================
五、历史记录查询（从服务器获取）
================================================================================
HISTORY_PUBLIC [数量]
        获取最近 N 条公开消息（默认 20，最大 100）。
        示例：HISTORY_PUBLIC 50

HISTORY_PRIVATE <用户名> [数量]
        获取与指定用户的私聊历史（默认 20，最大 100）。
        示例：HISTORY_PRIVATE Bob 30

HISTORY_GROUP <群组名> [数量]
        获取指定群组的历史消息（默认 20，最大 100）。
        示例：HISTORY_GROUP DevTeam 40

================================================================================
六、文件传输（客户端发起）
================================================================================
SEND_FILE <用户名> <本地路径>
        发送私密文件给好友（仅好友且未屏蔽）。
        示例：SEND_FILE Bob /home/user/report.pdf

SEND_GROUP_FILE <群组名> <本地路径>
        发送文件到群组，所有群成员可下载。

RESUME_UPLOADS
        重新尝试所有中断的上传任务（从上次断点继续）。

注意：文件大小 ≤ 20 MiB，支持断点续传。下载由服务器推送，无需手动命令。

================================================================================
七、未读与待办
================================================================================
PENDING
        检查所有待处理事项：好友请求、群组申请、离线消息、离线文件、Redis 未读计数。

================================================================================
八、本地（SQLite）管理命令（不经过服务器）
================================================================================
LOCAL_HELP
        显示本地命令帮助。

LOCAL_DB
        显示 SQLite 数据库路径和下载目录。

LOCAL_STATS
        显示本地缓存中各类消息和文件的数量。

LOCAL_HISTORY_PRIVATE <用户名> [数量]
        从本地缓存查询与某人的私聊历史（默认 20，最大 200）。
        示例：LOCAL_HISTORY_PRIVATE Bob 30

LOCAL_HISTORY_GROUP <群组名> [数量]
        从本地缓存查询群聊历史（默认 20，最大 200）。
        示例：LOCAL_HISTORY_GROUP DevTeam 40

LOCAL_FILES [数量]
        列出本地缓存的已传输文件记录（默认 20，最大 200）。
        示例：LOCAL_FILES 50

================================================================================
九、其他
================================================================================
WHO
        查看当前在线的所有用户列表。

HELP
        显示服务器端命令帮助（即本文档服务端部分）。

================================================================================
【常见错误提示】
- [error] unknown command        → 命令名错误，检查是否输入正确。
- [error] usage: ...            → 参数数量或格式错误，查看示例。
- [error] username already exists → 注册时用户名已被占用。
- [error] invalid username or password → 登录失败，检查大小写。
- [error] target account does not exist → 私聊/加好友时对方用户不存在。
- [error] only friends can ...  → 操作仅限好友，先添加好友。
- [error] you must LOGIN before ... → 未登录，先执行 LOGIN。
- [local error] ...             → 本地 SQLite 或文件操作错误，查看具体提示。
